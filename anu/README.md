# anu/ — Replication Package

Anu-framework replication package for the RSCD project: replication and
1860–2025 extension of the empirical material in Shaikh (2016),
*Capitalism: Competition, Conflict, Crises*.

This directory is the template-conformant **pipeline layer**: it tells you how
every shipped dataset is reproduced from public sources. The data itself
(`chopped/`, `extenbooks/`), the per-series pipeline code (`code/`), the
self-contained runner (`replicator/`) and the per-series documentation
(`docs/series/`) are the same repository's deliverables — this package
orchestrates them.

## Layout

```
anu/
  series_registry.json   118-series registry (generated — see below)
  scripts/
    _build_registry.py   regenerates series_registry.json from the canonical registries
    L01_fetch_fred.py    per-source fetchers (FRED, BEA, World Bank, IMF,
    ...                  Census, Shiller, Damodaran, bundled inputs)
    P01_construct_series.py   run the construction pipeline (all/one/family)
    P02_write_chopped.py      stage final chopped CSVs + MANIFEST.csv
    V01_validate.py           package-level validation gate
  dpr/                   Data Provenance Records (per source + family index)
  data/                  produced at run time (gitignored)
    raw/ processed/ final/
  requirements.txt       minimal Python dependencies
  Makefile               make registry / fetch-* / construct / validate / all
```

## Quick start

```bash
pip install -r anu/requirements.txt

# 1. Key-free validation of the shipped reference data (runs in CI)
python anu/scripts/V01_validate.py

# 2. See what a source serves (dry run)
python anu/scripts/L01_fetch_fred.py

# 3. Reproduce one series end-to-end (FRED key needed for most extensions)
cp replicator/config/api_keys.env.example replicator/config/api_keys.env  # fill FRED_API_KEY
python anu/scripts/P01_construct_series.py --series S201

# 4. Full reproduction (~45 min clean cache) + staging + gate
python anu/scripts/P01_construct_series.py --all
python anu/scripts/P02_write_chopped.py
python anu/scripts/V01_validate.py --dir anu/data/final/chopped
```

Or with make: `make -C anu check` (key-free), `make -C anu all` (full run).

## API keys

| Source | Key | How |
|---|---|---|
| FRED | `FRED_API_KEY` (free) | https://fred.stlouisfed.org/docs/api/api_key.html — several series also work keyless via fredgraph CSV |
| BEA | `BEA_API_KEY` (free) | https://apps.bea.gov/api/signup/ — extensions only; book period is bundled |
| World Bank, IMF, Census, Shiller, Damodaran | none | open access |
| Bundled book-period inputs | none | shipped in `replicator/inputs_bundled/` |

## series_registry.json

Generated by `scripts/_build_registry.py` from the canonical repo-root
`series_registry.json` + `SUBSOURCE_METADATA.json` (single source of truth —
never hand-edit the generated file). Each entry carries: title, description,
source (name/URL/license), construction method, scripts, fetchers,
transformations, units, frequency, coverage, producibility flag, documentation
links and quality status.

Regenerate after changing the canonical registries:

```bash
python anu/scripts/_build_registry.py
```

## Namespace note

Two script-prefix namespaces coexist by design: the repo's pipeline phases
(`code/S00_setup`, `L01_loaders`, `P02_processors`, `V03_validators`,
`O06_output`) classify **what a script does** in the canonical pipeline; the
`anu/scripts/` L##/P##/V## files are this package's **entry points** into that
pipeline. `L01_fetch_fred.py` (anu) does not replace `code/L01_loaders/`
(canonical); it invokes them per source family.

## What ships vs what stays internal

Ships: scripts, generated registry, DPRs, requirements, Makefile.
Stays internal: production prompts, internal tooling, benchmark numbers.
