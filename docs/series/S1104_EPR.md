# S1104 — Extension Provenance Record

**Construction**: `composite` (three independent overlay components)
**Extension method**: per-component (DOTS for trade, BIS PPI EER for REER, WDI for relative GDP)
**Status v1**: `partial` — book period emitted; S1104-A/S1104-B post-2009 extension deferred to Phase 9
**Revised**: 2026-07-02 (FU-1 / campaign C6) — **S1104-C BUILT** (was deferred)

---

## 1. Why this series is extendable

Two of three components (trade, REER) inherit the extension paths of S1101-A
and S1102-B respectively. The third (relative real GDP) is a new data demand.
All three are independent overlay lines, so each is extended separately and
re-plotted on the same x-axis.

## 2. Per-component method (planned)

### S1104-A net-trade ratio
Fetch IMF DOTS US X and M, compute `(X-M)/(X+M)`. Same source as S1101-A.

### S1104-B US REER PPI
Inherit S1102-B BIS PPI EER substitute (see `S1102_EPR.md`). Proxy flag
inherited.

### S1104-C US/EU12 relative real GDP — BUILT 2026-07-02 (FU-1 / campaign C6)
Phase 4 resolution Q5: hold Shaikh's pre-1995 EU12 basket fixed (BE, DK, FR,
DE, GR, IE, IT, LU, NL, PT, ES, GB).

**Realized build.** OECD QNA was not needed: World Bank WDI `NY.GDP.MKTP.KD`
(real GDP, constant 2015 USD) has **complete coverage for all 13 countries
across 1960-2009** (0 gaps, verified 2026-07-02 — including Germany from 1960).
Method as implemented in `L01_S1104._build_relgdp`:
1. Fetch `NY.GDP.MKTP.KD` for the 12 EU members + USA via
   `S00_apis.worldbank_indicator` (open, no auth; CC-BY-4.0).
2. `EU12_sum[y] = Σ` of the 12 members' real GDP (constant 2015 USD).
3. `rel_raw[y] = US_realGDP[y] / EU12_sum[y]`  (US in the numerator, per the
   series name / DPR / registry formula and Shaikh's "opposite directions"
   text — the EPR's earlier loose "divide by US real GDP" wording is corrected
   to US÷EU12 here).
4. `index[y] = rel_raw[y] / rel_raw[2002] × 100`  (rebase 2002=100).

**Provenance.** Retrieved 2026-07-02; endpoint
`https://api.worldbank.org/v2/country/{ISO3}/indicator/NY.GDP.MKTP.KD?format=json`.
Raw per-country snapshot (with retrieval date) written to
raw source-data cache; API responses
cached under raw source-data cache. Subsource:
`WB_GDP_MKTP_KD_US_EU12` (SUBSOURCE_METADATA.json). Realized anchors:
1960=88.877210, 2002=100.0, 2009=105.711068 (index 2002=100).

**Fidelity caveat.** Concept-faithful to Fig 11.7's third line, but Shaikh's
own `RelGDPR` source is undocumented in Appendix 11.1, and no digitized
book-figure values exist, so exact numerical fidelity to the printed curve is
**unverified pending figure digitization** (see S1104_DPR §9).

## 3. Concept Match Justifications

- S1104-B BIS substitution: see S1102 EPR §2.
- S1104-C EU12 basket: Concept-exact match (same 12 countries Shaikh used);
  no proxy flag needed.

## 4. No-Proxy compliance

S1104-B inherits proxy=true from S1102. S1104-A and S1104-C are
concept-exact (no proxy).

## 5. No-Synthetic compliance

Any NaN propagates. Belgium pre-1993 in S1104-A is moot (US only).

## 6. Failure-mode table

| Failure | Action |
|---|---|
| IMF DOTS down | S1104-A `extension_status: api_unavailable` |
| BIS down | S1104-B inherits S1102 degradation |
| WDI missing a country-year | `EU12_sum` uses `min_count=12` → NaN that year (no partial-basket aggregate); no proxy/interpolation |
| WDI unreachable | S1104-C `s1104c_status: api_unavailable`; S1104-A/B still emit |

## 7. CD2 divergence pre-disclosure

CD2's S063 reported trade-balance values matching `(X-M)/(X+M)`; RSCD's
S1104-A reproduces these. **FU-1 finding:** CD2's "S063 relative GDP" column
is a *mislabeled real-interest-rate differential*, NOT a US/EU12 GDP series —
it was deliberately NOT ported. RSCD's S1104-C is a fresh, fully-documented
WDI reconstruction on the fixed pre-1995 EU12 basket (built 2026-07-02).
