## 1. Why this series cannot be extended

S1702 is a cross-sectional snapshot at a single tax year (2011). Under the
rule that extensions apply only to time-series data, cross-sectional
snapshots are not extended — each subsequent IRS Statistics of Income (SOI)
release (Publication 1304, Tax Year YYYY) is a separate series, not a
continuation.

## 2. Future-tax-year reconstruction (not an extension)

A user wishing to update Figure 17.2 to a more recent tax year would:
1. Download IRS SOI Pub 1304 Table 1.4 for the desired year.
2. Apply the same bin-midpoint -> frequency -> cum-from-above pipeline.
3. Register it as a separate cross-sectional series.

This is NOT an extension of S1702 and would be a new RSCD series.

## 3. Source substitutions and forecast data

The IRS is itself the canonical authoritative source. No substitution
required. The open-ended $10M+ bin has no midpoint in the workbook and is
not imputed (no value invented).

## 4. Divergence from earlier replications

An earlier replication's S103 reference values were the Frequency column
(FPR017_C3), not the Cumulative-from-Above (FPR017_C5). This is corrected
here; RSCD v1 uses column F and matches to <0.01%.
