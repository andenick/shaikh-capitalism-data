# S1003 — Extension Provenance Record

**Series**: S1003 — Relative Price of Finance
**Construction classification**: `formula` (derived)
**Extension method**: recompute formula from extended components (No-Lazy-Splices)

---

## 1. Extendability

Yes — the underlying components (`iblong` → FRED AAA; `USWPI` → FRED PPIACO reindexed to 1947=100) are both extendable. The ratio is recomputable through the most recent annual observation.

## 2. Method

```
For each year y >= 2012:
  i[y] = S1002 extended yield   (FRED AAA annual mean)
  p[y] = S1002 extended PPI     (FRED PPIACO annual mean * scale, scale = USWPI[2011]/PPIACO[2011])
  S1003[y] = (i[y] / i[1947]) / (p[y] / p[1947])

i[1947] and p[1947] are fixed at book-period values (read from Appendix10_USLR.xlsx).
```

## 3. No lazy splice

Per the Anu rule: this is a derived (formula) quantity; we never splice the published `ib/p` ratio. We re-fetch the components and recompute the ratio. This preserves analytical meaning across the splice boundary.

## 4. Proxies

**None.** AAA and PPIACO are direct continuations of the components Shaikh used.

## 5. Failure modes

If S1002 components are unavailable for extension, S1003 publishes book period only with `extension_status: components_unavailable`.

## 6. CD2 divergence

Informational only.

## Notation (plain-language key)

- **CD2 / CD3** — the predecessor builds of this dataset (earlier reconstructions; a "CD2 divergence" note reports how the earlier build differed, for information only).
- **Phase 5 / Phase 6** — Anu pipeline stages: Phase 5 is ingestion (building the book-period series); Phase 6 is extension (carrying the series forward with live data).
- **IROP / ROP** — incremental / average rate of profit (the return on newly added capital, or on the whole capital stock).
- **FRED** — the Federal Reserve Bank of St. Louis public economic-data service (source of the modern extension inputs).
- **BEA / NIPA** — the U.S. Bureau of Economic Analysis and its National Income and Product Accounts.
- **No-Lazy-Splices rule** — an internal quality rule: a derived (formula) quantity is never extended by splicing onto the published rate; the formula is recomputed from extended components so it stays analytically consistent across the book/extension boundary.
- **L01 / V03** — the load and validate scripts that build and check the series.
