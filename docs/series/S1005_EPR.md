# S1005 — Extension Provenance Record

**Series**: S1005 — Dividend Yield vs Bond Yield
**Construction**: `composite`
**Extension**: same-series continuation via Shiller `ie_data.xls` + FRED CSV

---

## 1. Extendability

Yes. Shiller updates `ie_data.xls` continuously; FRED `GS10` and `AAA` are live.

## 2. Method

```
DIVIDEND YIELD (S1005-D dividend)
  Shiller ie_data.xls 'Data' sheet, monthly D and P columns
  Annual aggregation: mean of monthly (D/P*100) over each calendar year
  Append years > 2011 to S1005-A book values

10YR GOV YIELD (S1005-D gov)
  Prefer Shiller GS10 column from ie_data.xls (annual mean)
  Fallback to FRED fredgraph.csv?id=GS10
  Append years > 2011

CORPORATE YIELD
  Inherited from S1002 extension (FRED AAA)
```

## 3. Proxies

None — Shaikh's dividend yield IS Shiller's published series.

## 4. Synthetic data

None; FRED partial-year NaN propagates.

## 5. Failure modes

| Failure | Action |
|---|---|
| Shiller `ie_data.xls` HTTP non-200 | Use FRED `MULT` (Multpl mirror) — not implemented in Phase 5, degrade to book-period only |
| FRED GS10 unavailable | Use Shiller GS10 column only |
| Both unavailable | Publish book period only |

Informational only.

## Notation (plain-language key)

- **CD2 / CD3** — the predecessor builds of this dataset (earlier reconstructions; a "CD2 divergence" note reports how the earlier build differed, for information only).
- **Phase 5 / Phase 6** — Anu pipeline stages: Phase 5 is ingestion (building the book-period series); Phase 6 is extension (carrying the series forward with live data).
- **IROP / ROP** — incremental / average rate of profit (the return on newly added capital, or on the whole capital stock).
- **FRED** — the Federal Reserve Bank of St. Louis public economic-data service (source of the modern extension inputs).
- **BEA / NIPA** — the U.S. Bureau of Economic Analysis and its National Income and Product Accounts.
- **No-Lazy-Splices rule** — an internal quality rule: a derived (formula) quantity is never extended by splicing onto the published rate; the formula is recomputed from extended components so it stays analytically consistent across the book/extension boundary.
- **L01 / V03** — the load and validate scripts that build and check the series.
