## 1. What it is (book definition + Appendix 11.1 + figure)

S1101 is the panel behind **Figure 11.2** (book p. 524): the annual **export/import ratio in common
currency (USD)** for fifteen major OECD countries, 1960–2009, one line per country. Shaikh's own caption
and text fix the definition verbatim (`research.book_quotes[0]`, role=definition, p. 523): *"Figure 11.2
depicts the trade balances of fifteen major countries from 1960 to 2009. These are measured as the
export-import ratio in common currency, so that a ratio greater than one signifies a trade surplus and a
ratio below one signifies a trade deficit."* The figure title (`book_quotes[1]`, p. 524) is *"Trade
Balances in Major Countries, 1960–2009 (Exports/Imports)."*

Values ship from **Appendix 11.1** (Shaikh's own distributed workbook `Appendix11_XMData.xlsx`, 15
countries × 1960–2009 with X, M, X+M and the X/M column), local copy under
`SalvagedInputs/book_data/ShaikhChoppedTables/` (`S1101_DPR.md` §3). Fig 11.2 is the **empirical anchor**
that opens the chapter: it exhibits *persistent, non-mean-reverting* trade imbalances across the OECD, which
is the phenomenon standard PPP-based exchange-rate theory cannot explain and which Shaikh's relative-real-
unit-labour-cost theory (S1102–S1103) is built to explain (`S1101_DPR.md` §2).

## 2. Source lineage (IMF IFS exports and imports, USD)

The lineage is fixed verbatim by Shaikh's Appendix 11.1.II (p. 875, `research.book_quotes[2]`, role=source):
*"Sum of Exports and Imports (EX+IM): From the International Monetary Fund (IMF), International Financial
Statistics (IFS), exports and imports in US dollars. Missing values for Belgium for 1960–1992 were taken
from AMECO Database … imports (UMGS) and exports (UXGS) in current prices … converted to US dollars using
the exchange rate (XNE)."*

| Input | Source | Role |
|---|---|---|
| **Exports X** (goods, current USD) | IMF **IFS** | numerator of X/M ratio |
| **Imports M** (goods, current USD) | IMF **IFS** | denominator of X/M ratio |
| Belgium 1960–1992 X+M | **AMECO** (UXGS/UMGS in ECU/EUR → USD via XNE) | gap backfill for one country |
| Trade balance ratio (derived) | `X_{c,t} / M_{c,t}` | Fig 11.2 line per country |

Formula (`research.formula`; `S1101_DPR.md` §4): `trade_balance_{c,t} = X_{c,t} / M_{c,t}`, ratio > 1 =
surplus, < 1 = deficit. The 15-country panel per Appendix 11.1.I is Australia, Belgium, Canada, Denmark,
Finland, France, Germany, Italy, Japan, Korea, Netherlands, Norway, Spain, Sweden, United Kingdom, United
States (`research.methodology_notes[1]`).

## 3. Why these sources — Shaikh's rationale + rejected alternatives

- **Why the X/M *ratio* in common currency, not a level or a percent-of-GDP.** Shaikh wants a
  scale-free, cross-country-comparable measure of trade (im)balance whose value 1.0 is an unambiguous
  break-even line, so fifteen very differently sized economies can be read on one axis and the *persistence*
  of imbalance is visible without normalising by GDP. Common-currency (USD) conversion is required so the
  ratio reflects real trade competitiveness, not domestic price levels.
- **Why IMF IFS goods exports/imports, NOT World Bank WDI exports/imports of goods and services.** The WDI
  BoP series (`NE.EXP.GNFS.CD`) bundles *services* into the flow; Shaikh's series is **goods-only** via IFS,
  because the chapter's competitive mechanism runs through tradable manufactured goods priced by producer
  prices (the same tradables logic that governs S1102's PPI deflation). Adopting WDI would inject a
  services concept-drift (`research.extension_candidates[1].concerns`). Rejected for the book concept; noted
  only as a *possible* extension fallback with a documented concept caveat.
- **Why NOT "percent of GDP."** CD2's markdown labelled a sibling series "Percent of GDP"; Shaikh's Fig
  11.2 is explicitly Exports/Imports (`research.methodology_notes[2]`). The MHR records X/M as the authorial
  choice; percent-of-GDP is a rejected mislabel, not Shaikh's construct.
- **Why AMECO only for Belgium 1960–1992.** IFS lacks separate Belgian X and M for the early period;
  Shaikh backfills the *combined* flow from AMECO rather than fabricate a ratio — so the Belgian **X/M
  ratio is left NaN 1960–1992** while X+M is preserved (`S1101_DPR.md` §7 caveat 2). This is Shaikh's own
  honest-gap discipline, faithfully reproduced.
- **Why exactly 15 countries — and why China is NOT among them.** Shaikh's Appendix 11.1.I panel is the set
  of OECD economies for which the full ULC/PPI/exchange-rate apparatus of the chapter exists; China is
  absent because the chapter's competitive-cost machinery cannot be built for it in the book period
  (`research.methodology_notes[1]`). CD2 added a China line (S060-E). RSCD keeps it only as an explicitly
  flagged `cd2_addition` comparator **excluded from Shaikh's 15-country aggregate**, not emitted in v1
  (`CH11_ADEQUACY_REPORT.china_in_S1101E_recommendation`; `review.F10`). Rejected as part of Shaikh's scope.

## 4. Methodological-change exposure — provider migration, not a proxy (KEY SECTION)

**S1101 is the only proxy-FREE series in the chapter** (`review.proxy_audit.proxy_false_series` = ["S1101"];
registry `S1101.proxy = false` on every subseries). Its inputs (IMF IFS goods X and M) are on a
**continuously maintained** source, so the post-2009 extension is a *same-agency, same-concept*
continuation — **no BLS-ILC discontinuation and no BIS substitution touch this series** (contrast S1102–
S1104). The only methodological exposure is *provider-code migration*, which is a concordance issue, not a
concept substitution:

- **IMF IFS → IMF DOTS / SDMX continuation.** The X and M flows continue to be published by the IMF via IFS
  and Direction of Trade Statistics (DOTS); the same X/M ratio is reconstructable year-by-year post-2009
  from raw DOTS flows (`S1101_EPR.md` §1–3). This mirrors the IFS-legacy-line → modern-SDMX-code migration
  documented project-wide (`Technical/docs/methodology/IFS_line_to_SDMX_remap.md`) — a *code_remap*
  annotation, explicitly **NOT a `proxy` annotation** (that doc §5). No concept match justification is
  required because the concept, agency and currency are unchanged.
- **German reunification break (1991).** IFS unified-Germany series begins 1991; the pre-1991 West Germany
  segment must be spliced. Shaikh's `Appendix11_XMData.xlsx` already handles this within the book period
  (`research.extension_candidates[0].concerns`); any extension inherits the same splice point.

**Temporal scope:** there is **no proxy at any date** for S1101. The book period (1960–2009) is Shaikh's
own Appendix 11.1; the deferred post-2009 extension is a same-source IFS/DOTS continuation. `proxy:false`
is correct on all subseries and must not be conflated with the S1102–S1104 BLS-ILC→BIS proxy.

  decision, not a fidelity defect.

## 6. Forward risk

- **Extension is clean but not yet built (deferred).** Post-2009 X/M via IMF IFS/DOTS is a same-source
  continuation with `not_attempted_v1` status; the only care items are the 1991 Germany splice and the
  AMECO-URL update (old `ec.europa.eu/economy_finance/ameco/` 404 → `economy-finance.ec.europa.eu/…/
  ameco-database_en`, `CH11_ADEQUACY_REPORT` substitutions).
- **Do NOT growth-rate-splice via WDI.** Any extension must stay goods-only (IFS/DOTS); a WDI splice would
  silently add services and drift the concept (`research.extension_candidates[1].concerns`).
- **China re-fetch (optional).** Populating S1101-E requires an IMF IFS China X+M pull; keep it a flagged
  16th comparator, never fold it into Shaikh's 15-country statistics (`CH11_ADEQUACY_REPORT
  .china_in_S1101E_recommendation.phase5_implementation`).
- **Within-chapter unit contrast is intentional.** S1101 uses X/M; S1104-A uses (X−M)/(X+M). This is
  Shaikh's authorial presentation choice, preserved deliberately (`S1101_DPR.md` §7 caveat 3;
  `CH11_ADEQUACY_REPORT` Q3) — not a bug to reconcile away.
