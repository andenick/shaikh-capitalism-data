## 1. What it is (book definition + eq. 13.42–13.43 + figure)

S1301 is the single series behind **Figure 13.7** ("Actual and Equilibrium Paths of Output," book p. 633).
It is a **purely illustrative schematic**, not a record of observed output: `ln Y` on the vertical axis (model
units 8.0–12.5) plotted against an **unlabelled time index** t ∈ [0, 75] — *there are no calendar years and
no empirical observations* (`S1301_DPR.md` §1; `CH13_RESEARCH_SUMMARY.md`). The curve is a realisation of
Shaikh's eq. 13.43:

```
ln Y_t = ln Y_0 + alpha * t + eta_t,   eta_t = sum_{i=1..t} epsilon_i        (13.43)
```

a deterministic log-linear trend `ln Y0 + alpha·t` plus a stochastic random-walk-with-drift error term
`eta_t`. The build ships two subseries: **S1301-EQ** (the equilibrium trend `ln Y0 + alpha·t`) and
**S1301-ACTUAL** (the realised path `ln Y0 + alpha·t + eta_t`).

Shaikh's own figure caption is verified verbatim in the KB (`research.book_quotes[0]`, role=definition, p. 632;
`Body_Text/ch13_macro_dynamics.md` lines 1872–1873): *"Since the slope of the path of ln Yt is the growth
rate of output, a constant growth rate implies a constant slope (i.e., a straight-line path). Figure 13.7
depicts the log of actual output around one equilibrium path. As indicated by the other dotted lines, lines
parallel to this one also have the same slope and hence represent the same growth rate."*

**Why Shaikh drew it.** Fig 13.7 is the visual anchor of his classical proposition that actual output
*fluctuates around an equilibrium growth path* set by net profitability and the capacity–capital ratio
(eqs. 13.41–13.42), rather than being pinned by aggregate demand. The multiple parallel dotted lines make
the level/growth distinction concrete: different initial conditions `Y0` give different *levels* but the same
*slope* (growth rate α). It seeds the visualisation Shaikh re-uses for Figs 13.8/13.9/13.10 under different
shock configurations (out of scope for S1301; `CH13_RESEARCH_SUMMARY.md`).

## 3. Why this construction — Shaikh's rationale + rejected alternatives (analytic, immune to vintage drift)

Because there is no external series, the "methodological choices" are analytic, and the disclosed parameter
set is the RSCD authors' — **not** Shaikh's, because *Shaikh does not publish the parameter values used to draw
Fig 13.7* (`research.open_questions[1]`; `S1301_EPR.md` §2; `CH13_RESEARCH_SUMMARY.md` issue 2). The choices:

- **Why `formula`, not `direct`.** The plotted line is an analytical realisation of eq. 13.43, not a record of
  observed output, so construction is classed `formula` (`research.methodology_notes[3]`). Extension is
  `not_applicable_theoretical` — re-running the loader with a new seed yields a *different realisation of the
  same mathematical object*, not a continuation of an observed series (`S1301_EPR.md` §1).
- **Why `content_type: theoretical`, not `cross_sectional`.** The Phase-2 classifier stubbed S1301 as
  `cross_sectional`; Wave-C re-typed it to `theoretical` because Fig 13.7 has no calendar-time axis and no
  observations (`research.methodology_notes[1]`; `review_history`). Phase 4 RATIFIED the re-type
  (`series_registry.json` S1301.adequacy.issues_resolved[0]).
- **Disclosed illustrative parameters** (declared to satisfy No-Proxies-Without-Disclosure *by construction*;
  `L01_S1301.py` header lines 31–35; `S1301_EPR.md` §2; `series_registry.json` S1301.parameter_disclosure):

  | Parameter | Value | Justification |
  |---|---|---|
  | `ln Y0` | 8.0 | matches the chart y-axis lower bound |
  | `alpha` | 0.03 | 3% per period — a typical real growth rate |
  | `sigma_epsilon` | 0.015 | generates visually realistic fluctuations |
  | `seed` | 42 | reproducible RNG (the ONE sanctioned exception — see §5) |
  | `t_max` | 75 | matches the chart x-axis range |

- **Rejected alternatives.** (a) Matching Fig 13.7 to any *historical* output series — rejected: the printed
  curve is not intended to match any real economy (`research.open_questions[1]`). (b) Treating it as
  `cross_sectional`/`time_series` and attempting an extension — rejected as category error (`S1301_EPR.md` §1).
  (c) Fabricating undisclosed "book" parameters — rejected in favor of transparently disclosed author-chosen
  values (`S1301_EPR.md` §3).

**Immune to NIPA/IO vintage drift.** Sections 2–3 describe a self-contained simulation with no external input,
so no BEA/BLS comprehensive revision, no I-O benchmark, and no concordance vintage can touch S1301. It is
structurally exempt from the NIPA/IO change timelines that govern the empirical chapters
(`_timelines/NIPA_CHANGE_TIMELINE.md`, `_timelines/IO_CHANGE_TIMELINE.md` do not apply here).
