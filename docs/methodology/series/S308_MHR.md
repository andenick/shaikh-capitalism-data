## 1. What it is

S308 is the **composite behind Figure 3.10**: five overlaid necessary-good (`x1`) demand curves — one
theoretical curve plus the four micro-foundations models (Neoclassical Homogeneous, Neoclassical Heterogeneous,
Whimsical/Becker, Imitate-Innovate/Dosi) — with price `p1` swept `1.0 → 1.5` (`x1` axis ~70–110). Five
subseries `S308-A…E`, 255 chopped rows (5 × 51). It is the chapter's **capstone "robust insensitivity"
illustration**: Shaikh's own text (`research.book_quotes[0]`, p. 99): *"…the very different micro foundations
of the various models have essentially no effect on the aggregate results."* Table 3.1 (p. 100) reports the
demand elasticity `ex1,p1 ≈ −0.93` across the theoretical baseline and all four models — the numeric proof of
insensitivity.

## 2. Source lineage

**Single primary source: Shaikh (2016), Figure 3.10 (p. 99) + Table 3.1 (p. 100); eqs. (3.5)/(3.6); simulation
parameters p. 99.** No external data agency.

- **S308-A (theoretical):** `L01_S308.py` evaluates the analytic demand `x1_demand(p1)` from eq. (3.5) with the
  book-stated simulation parameters `y = 200, c = 0.50, x1min = 10, p1 = 1, p2 = 2`
  (`book_quotes[1]`/`[2]`, p. 99; `_ch3_helpers.py` `SIM_*`). Exact: chopped `105 / 85 / 71.67`
  (`CH03_review.touchpoints` S308).
- **S308-B…E (labelled "NetLogo"):** **NOT re-simulated.** The loader constructs each as the analytic curve `×`
  a **fixed scalar offset** — `0.998 / 1.003 / 0.995 / 1.005` (i.e. `−0.20% / +0.30% / −0.50% / +0.50%`;
  `NETLOGO_OFFSETS_PCT` in `L01_S308.py:32-37`) — chosen to reproduce the ±2% spread visible in the printed
  figure. Their `subsource_id` is `SHAIKH_2016_NETLOGO_SIMS`, but **the true construction is `analytic curve ×
  constant`, not NetLogo output.**

## 3. Why these sources — Shaikh's rationale + rejected alternatives (and a provenance-label correction)

- **Why four contrasting micro-foundations at all.** This is the *entire thesis of the chapter*: aggregate
  demand and Engel curves are the same whether agents are hyper-rational-identical, hyper-rational-heterogeneous,
  whimsical (Becker 1962's impulsive consumer), or imitative-innovative (Dosi et al. 1999). Shaikh runs four
  deliberately incompatible behavioural worlds to show the macro pattern survives all of them
  (`CH3_RESEARCH_SUMMARY.md` "Cross-series structure").
- **Why the book-stated simulation constants (`y=200, c=0.5, x1min=10, p1=1, p2=2`).** Shaikh fixes these "for
  the sake of comparison" so the only thing differing across models is the *behavioural rule*, isolating the
  micro-foundation as the sole variable (`book_quotes[1]`, p. 99). The build reuses exactly those constants.
- **Why the price sweep `p1: 1 → 1.5`.** Book-stated: *"The demand curve for x1 is generated by raising its
  price from 1 to 1.5 by increments of 0.01"* (`book_quotes[2]`, p. 99) — hence 51 grid points.
- **PROVENANCE-LABEL CORRECTION (F-CH3-03, HIGH — do not propagate the mislabel).** Shaikh's *book* genuinely ran
  NetLogo simulations (footnote 21, p. 99; Amr Ragab acknowledged; "programs… available on request"). But the
  **RSCD loader did not run them** — the NetLogo source is not publicly archived, random seeds are unstated, so
  exact Monte-Carlo reproduction is impossible (`research.open_questions`). The build therefore *tabulated*
  B–E as small fixed multiples of the theoretical curve. The registry `construction_steps` claim these were
  "read off the printed figure" and the `subsource_id NETLOGO_SIMS` implies real simulation — **both are
  misleading**. The honest description is: **S308-A = analytic (eq. 3.5); S308-B…E = analytic × a fixed
  per-model scalar (0.998/1.003/0.995/1.005), consistent with the printed ±2% spread; no simulation was run.**
  This MHR records the true construction and treats the NETLOGO_SIMS label strictly as a defect to fix.
- **Rejected alternative — re-implementing the four NetLogo models.** Feasible from the verbal specs (pp. 96–98)
  but would produce *different* Monte-Carlo draws (seeds unstated), so it could not reproduce the printed curves
  exactly; the build chose faithful near-copies of the figure instead of unfaithful fresh simulations.

## 5. Replication fidelity

- **Theoretical curve exact** (`105 / 85 / 71.67`); Table 3.1 elasticity `ex1,p1 ≈ −0.93` matches across models.
- **Circular cross-curve validator (F-CH3-03 / F-CH3-11, HIGH).** V03's ±2% cross-curve check (`V03_S308.py`)
  can never fail: B–E are *defined* as A × (1 ± ≤0.5%), so the "all models within 2% of theoretical" test is
  tautological, not an independent confirmation of Shaikh's claim. V03 also checks only shape/bounds
  (`VALIDATOR_TOL_PCT = 0.5`) and never `registry.reference_values` (F-CH3-11); tolerances are uncoordinated
  (0.5% vs 1%, F-CH3-13).
- **Honesty status: disclosed (D13 PASS, not a gate failure).** The theoretical/tabulated nature is disclosed;
  the mislabelled subsource is a provenance-label defect, not synthetic-data fabrication
  (`CH03_review.gates.D13`; `touchpoints` S308 "honesty").
- **F-CH3-05 / F-CH3-07 (MEDIUM):** `x_value` (price `p1`) dropped from chopped — the demand curve cannot be
  plotted vs its price axis without a registry `domain` join; triage reason wrongly says ch03 unextracted (the
  simulation section pp. 96–100 and Table 3.1 are in the KB).
